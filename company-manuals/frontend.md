# 회사 매뉴얼 | 프론트엔드 개발

이 문서는 시연용 가상 회사의 프론트엔드 신입 업무 매뉴얼입니다.

## 개발 환경 시작

저장소 안내의 런타임 버전을 확인합니다. 잠금 파일 기준으로 의존성을 설치하고 개발 서버를 실행합니다. 로그인, 홈, 온보딩 프로세스가 열리는지 확인하고, 변경하기 전에 브라우저 개발자 도구에서 네트워크와 콘솔을 한 번씩 점검합니다.

## 화면과 API 상태 확인

목록 화면에서 로딩, 결과 없음, 요청 실패와 정상 상태를 각각 확인합니다. 메뉴로 상세에 진입한 뒤 주소를 직접 열거나 새로고침했을 때도 같은 화면에 도달하는지 비교합니다. 검증 기록에는 역할, 경로, 실제 발생 상태와 기대 결과를 함께 적습니다. 요청의 실제 동작과 화면 문구가 다르면 둘을 분리해 보고합니다.

## 변경 검토

작은 UI 변경을 만들면 키보드로 컨트롤을 이동하고 실행할 수 있는지 확인합니다. 좁은 화면에서 버튼 또는 안내가 잘리는지 살펴보고, 타입 검사와 관련 테스트를 실행합니다. 변경 전후를 짧게 비교할 수 있는 증거를 준비한 뒤 멘토에게 검토를 요청합니다.

## 신입 확인 과제

하나의 사용자 흐름을 선택해 정상, 빈 상태, 오류 세 가지를 기록합니다. 발견한 문제 하나는 재현 절차로 정리하고, 바꿀 부분은 작은 단위로 제안합니다.
