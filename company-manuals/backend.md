# 회사 매뉴얼 | 백엔드 API 개발

이 문서는 시연용 가상 회사의 백엔드 신입 업무 매뉴얼입니다.

## 요청 계약 읽기

작업을 시작할 때 API 문서에서 요청 필드, 응답 형태와 권한을 확인합니다. 같은 기능을 신입, 멘토, HR이 서로 다른 범위에서 쓸 수 있으므로 어떤 역할과 회사의 데이터를 다루는지 기록합니다.

## 상태 전환과 입력 검증

온보딩 과제 제출을 예로 시작 전 상태, 검토 대기, 승인 또는 보완 요청의 전환을 글로 정리합니다. 빈 값, 잘못된 범위, 권한이 없는 역할을 테스트 데이터로 확인합니다. 중복 요청이나 동시 변경이 있는 경우에도 같은 과제가 두 번 처리되지 않는지 검증합니다.

## 테스트와 인계

특정 역할에 허용한 읽기 범위가 다른 회사나 다른 신입에게 노출되지 않는지 통합 테스트로 확인합니다. API 응답의 예상 코드와 실제 결과를 표로 정리합니다. 확인에 사용한 샘플 데이터와 명령을 남기고, 변경 후 앱 화면에서 같은 흐름이 보이는지 멘토와 재확인합니다.

## 신입 확인 과제

과제 승인, 면담 확정 또는 퀴즈 제출 중 하나를 골라 성공·잘못된 입력·권한 거부 시나리오를 만듭니다. 각 경우의 입력, 기대 상태, 결과를 정리합니다.
