# 회사 매뉴얼 | 계정과 자료 보안

이 문서는 시연용 가상 회사의 공통 업무 매뉴얼입니다.

## 초대와 계정 확인

가입은 회사가 발급한 초대 코드를 사용합니다. 가입한 뒤 워크스페이스 이름, 부서, 역할을 확인합니다. role이나 부서가 다르면 직원 관리 담당자에게 정정을 요청하고, 다른 사람의 계정으로 로그인하지 않습니다. 회의나 시연 중에는 비밀번호나 브라우저의 로그인 토큰을 공유하지 않습니다.

## 자료의 공개 범위

사내 매뉴얼의 제목과 열람 대상이 일치하는지 확인합니다. 공유 링크를 보내기 전에 상대가 그 자료를 볼 권한이 있는지 먼저 확인합니다. 과제에는 공개 시연용 예시만 첨부하며 실계정, 고객 정보, 시크릿은 올리지 않습니다. 샘플 데이터를 만들 때는 가상의 이름과 값만 사용합니다.

## 문제 신고

잘못된 계정 권한이나 공개 범위를 발견하면 담당 멘토 또는 HR에게 발생 화면, 사용 역할, 예상 결과와 실제 결과를 전달합니다. 화면 캡처에는 개인정보를 넣지 않습니다. 조치 후 같은 계정으로 다시 해당 흐름을 확인합니다.

## 신입 확인 과제

초대 정보와 본인 권한을 확인하고, 공유 가능한 자료와 내부 전용 자료의 예를 각각 하나씩 적습니다. 문제가 있을 때 어느 담당자에게 어떤 정보를 전달할지 세 문장으로 정리합니다.
