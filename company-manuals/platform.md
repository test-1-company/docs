# 회사 매뉴얼 | 플랫폼 배포와 장애 확인

이 문서는 시연용 가상 회사의 플랫폼 신입 업무 매뉴얼입니다.

## 배포 전후 확인

개발 환경에서 검증한 변경을 확인하고 어떤 브랜치와 커밋이 배포에 쓰이는지 기록합니다. 배포 직후 정상 로그인과 홈 진입, 목록에서 상세 이동 및 새로고침을 확인합니다. 화면의 에러와 API의 통신 오류를 구분하고, 브라우저 네트워크의 응답 코드와 콘텐츠 종류를 기록합니다.

## 비동기 작업 관찰

AI 초안처럼 요청 이후 별도로 처리되는 작업은 요청 접수, 진행, 완료 또는 실패 순으로 점검합니다. 이미 생성된 결과를 앱이 불러오거나 저장하지 못하면 작업 상태와 저장 서비스가 받은 완료 이벤트를 따로 확인합니다. 로그에는 시크릿과 고객 원문을 남기지 않습니다.

## 장애 보고와 재확인

영향을 받는 환경, 역할, 경로, 처음 발견한 시각, 재현 순서를 적습니다. 복구한 뒤 기존에 막혔던 동일 동작과 영향을 받기 쉬운 주변 기능 하나를 다시 확인합니다.

## 신입 확인 과제

목록에서 열 때와 주소를 직접 열 때의 동작을 비교합니다. 예상과 다르면 브라우저 오류, HTTP 상태, 고친 뒤 확인할 시나리오를 한 장의 기록으로 만듭니다.
